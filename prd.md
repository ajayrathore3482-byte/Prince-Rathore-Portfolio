# 9. PERFORMANCE REQUIREMENTS

Performance is a critical requirement.

1. Lazy-load 3D assets.
2. Optimize textures and models.
3. Compress images.
4. Avoid unnecessary React re-renders.
5. Use efficient animation loops.
6. Avoid oversized 3D assets.
7. Implement loading fallbacks.
8. Optimize font loading.
9. Minimize unnecessary dependencies.
10. Test performance on mid-range mobile devices.

Target:
- Lighthouse Performance: 90+ where practical.
- Accessibility: 90+ where practical.
- Best Practices: 90+ where practical.
- SEO: 90+ where practical.

These are targets, not guaranteed scores.

# 11. SECURITY REQUIREMENTS

If a PHP backend is implemented:

- Validate all input on the server.
- Sanitize user input.
- Use prepared SQL statements.
- Protect against SQL injection.
- Implement spam protection.
- Never expose database credentials.
- Keep API keys in environment variables.
- Use HTTPS.
- Return safe error messages.

Never store private credentials inside frontend source code.
